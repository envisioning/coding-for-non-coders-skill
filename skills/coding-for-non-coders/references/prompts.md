# The guide gives starter prompts and project ideas

These come from the guide's "Your first 10 minutes" section and its project idea exercise. Offer them as examples. The person's own idea always comes first.

## Starter prompts describe a small app

Each one describes a small app by what it should do and what should be on screen.

- Build me a simple habit tracker app. It should have a list of habits I can add and remove. Each habit has a checkbox for each day of the current week. Show the current streak for each habit. Make it look clean and modern with a dark theme.
- Build me a personal bookshelf app. I can add books with a title and author, mark them as reading or finished, and see stats on how many books I've read this year. Use a clean card layout.
- Build me a Pomodoro timer with a circular progress ring. Let me set focus and break durations. Track how many focus sessions I complete today. Play a short chime when the timer ends.
- Build me a daily journal app. Each entry has a date, a mood selector (five emoji options), and a text area. I want to see my mood trend for the past 30 days as a simple line chart.
- Build me a recipe saver. I paste a URL and it extracts the recipe name, ingredients, and steps. I can browse my saved recipes and filter by ingredient. Keep it minimal.
- Build me a split-the-bill calculator. I enter people's names and expenses, and it tells me who owes whom. Handle uneven splits and shared items. Make it mobile-friendly.

Note for Claude.ai and Cowork: the recipe saver needs to fetch other websites, which a page in the browser usually cannot do. Suggest pasting the recipe text instead.

## Follow-up prompts change what already works

Use these to show what a good second request looks like: a few specific changes to something that already works.

- Add a progress bar at the top that shows my overall completion rate for this week. Also add a button to clear all checkmarks and start fresh. Make the streak count show a fire emoji when it's 3 days or more.
- Add a search bar that filters the list in real time. When there are no results, show an empty state with a suggestion. Also add a subtle entry animation when items appear.
- Add a dark/light mode toggle in the top right corner. Also add a confetti animation when I complete a goal or finish a session. Make the UI feel more polished with hover states.
- Add drag-and-drop reordering to the list. Also add an export button that downloads the data as a JSON file. Show a toast notification when the export completes.

Each of these asks for two or three things. For a first-time builder, suggest sending one of them at a time.

## Twenty project ideas help when the person is stuck

When the person does not know what to build, pick three that fit what they told you about their work or life, and let them choose.

1. Help me build an app that turns a spreadsheet into a simple dashboard with one chart I pick.
2. I want to build an app that tracks habit streaks with a calendar heatmap and sends me one daily nudge.
3. Build me an app that's a link-in-bio page I can edit by pasting a Google Sheet URL.
4. Help me build an app that scrapes recipes and saves ingredients and steps to a list I can tick off while cooking.
5. I want to build an app that posts a micro blog or changelog from a Notion page or Markdown file.
6. Build me an app that splits expenses for trips or shared bills and outputs who pays whom.
7. Help me build an app that stores quotes or highlights I paste and lets me search or export them later.
8. I want to build a tiny CRM for my freelance clients: name, last contact, and one note.
9. Build me an app that tracks my reading list: what I started, finished, and want to read next.
10. Help me build an app that logs mood or energy with a few tags and a weekly summary view.
11. I want to build an app that shows a countdown or count-up to a personal milestone (launch, exam, trip).
12. Build me an app that's a one-page portfolio pulling project titles and links from a JSON or CSV file.
13. Help me build an app that generates a daily or weekly prompt for journaling or team retrospectives.
14. I want to build a small API that returns a random tip, quote, or link from a list I maintain.
15. Build me an app that exports my browser bookmarks into a searchable Markdown page.
16. Help me build an app that's a "what should I work on?" roulette picking from my backlog or goals list.
17. I want to build a minimal feedback form that appends responses to a Google Sheet or Airtable.
18. Build me an app that's a personal "today I shipped" log with tags and optional public RSS.
19. Help me build an app that converts timezones and shows a few key cities and good times to call.
20. I want to build a tiny app where I paste JSON and explore it in a simple tree or table view.

Ideas 3, 5, 14, 17 and 18 connect to outside services or need hosting. In Claude.ai and Cowork, build them with sample data first, and say which part needs Claude Code or a hosting service later.

## Each role tends to build different things

The guide lists what different people tend to build. Use it to suggest an idea that fits the person's job.

- Designers: interactive prototypes, design tools, portfolio sites.
- Marketers: landing pages, dashboards, lead generation tools, SEO analyzers.
- Founders: first versions of a product, internal tools, customer portals.
- Researchers: data visualizations, survey tools, analysis scripts.
- Educators: quiz apps, curriculum tools, student dashboards.
- Operations: workflow automations, reporting tools, inventory trackers. Replacing a manual spreadsheet process is a common first project.
